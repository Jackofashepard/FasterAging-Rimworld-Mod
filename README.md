# Faster Aging

I am not the original author.

Original author: Verdiss
Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=1850802618
Upstream: https://github.com/Verdiss/FasterAging-Rimworld-Mod

Faster Aging lets you set how fast pawns and animals age biologically. It needs HugsLib. The default multiplier is 1, which is normal aging. It replaces the storyteller aging rates.

Verdiss allows non-commercial redistribution with credit. This fork adds RimWorld 1.6 to the supported versions list. The assembly is still the 1.5 build, which is what RimWorld 1.6 loads when a mod has no 1.6 folder.

Source code for the Rimworld mod Faster Aging. See Releases for non-Steam mod distributions.
